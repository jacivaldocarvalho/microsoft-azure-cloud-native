Hands-on work developed from the **Microsoft Azure Cloud Native Bootcamp**, offered by [DIO](https://www.dio.me/) in partnership with **Microsoft**.

## Implemented Project

The current implementation improves the bootcamp's Lab 1 e-commerce challenge. It retains the original goal of storing product data and images in Azure while adding reproducible Terraform infrastructure, private Blob access, application validation, automated tests, deployment checks, and cleanup procedures.

The application uses Python and Streamlit, Azure SQL Database, Azure Blob Storage, Terraform, and GitHub Actions.
